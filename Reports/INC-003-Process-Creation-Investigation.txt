9. SECURITY LESSON
------------------
Process creation monitoring is valuable during endpoint investigations because
it allows analysts to establish process lineage.

A SOC analyst should correlate:

- User account
- Process name
- Process path
- Parent process
- Command line
- Timestamp
- Elevation information
- Other surrounding security events

A process such as PowerShell creating another process should not automatically
be classified as malicious. Context and correlation are required before
determining whether the activity is suspicious.
